# 유성구 야간 보행 안전 분석 팀원 공유본

## 포함 파일

- `scripts/`: 전체 Python 분석·전처리·지도 생성 코드
- `data_clean/`: 전처리된 CSV와 GeoJSON
- `outputs/maps/`: 정적 PNG 지도 7개와 대화형 HTML 지도
- `outputs/tables/`: 전처리 점검표·통계표·상태 워크북
- `outputs/유성구_야간보행안전_중간보고_발표구성안.md`
- `README.md`, `requirements.txt`

## 제외 파일

- `data_raw/`: 약 508MB의 공공데이터 원본이므로 공유본 용량을 줄이기 위해 제외
- `work/`: 설치 라이브러리·캐시·중간파일이므로 제외
- `__pycache__/`: Python 실행 캐시이므로 제외

원본부터 전체 파이프라인을 다시 실행하려면 프로젝트 담당자에게 `data_raw` 폴더를 별도로 받아 같은 위치에 넣어야 한다.

## 먼저 확인할 파일

1. `outputs/유성구_야간보행안전_중간보고_발표구성안.md`
2. `outputs/maps/yuseong_night_safety_map.html`
3. `outputs/tables/yuseong_interim_status.xlsx`
4. `README.md`

## Python 실행환경

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

원본 `data_raw`까지 준비된 경우 다음 명령으로 전체 과정을 실행할 수 있다.

```powershell
python scripts\run_all.py
```
